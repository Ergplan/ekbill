# Responses to the stage reviews

What was done with each finding of the independent stage reviews (rule 12, `docs/stages/stage-N-review-k.md`). A review reads one stage's diff, so it sees the code as it was at the end of that stage; a later stage may already have changed it. Each finding is checked against the code as it is now and is one of:

- **Fixed:** with a test that fails without the fix.
- **Already fixed:** a later stage changed it; where.
- **Kept:** a decision, with the reason; or a gap, recorded in `KNOWN-GAPS.md`.
